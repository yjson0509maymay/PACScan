# PACScan v1.4.0 MRI 슬라이스 이동

- 변경일: 2026-07-26 KST
- 변경 범위: 원본 MRI 및 전처리 결과 뷰어

## 구현 내용

- 축상면, 관상면, 시상면에 각각 독립 슬라이더 제공
- 원본 MRI의 실제 3D shape를 기준으로 방향별 슬라이더 범위 생성
- 전처리 결과의 56×56×56 볼륨 전체 탐색
- 현재 위치를 `현재 슬라이스/전체 슬라이스` 형식으로 뷰어 배지에 표시
- 새 DICOM 폴더를 선택하면 기존 슬라이스 위치를 초기화
- 축상·관상·시상면의 명칭을 한글로 유지

## 데이터 처리

`preprocessing_adapter.render_nifti_views()`가 업로드 원본 또는 실제 전처리 NIfTI를
canonical 방향으로 읽고 사용자가 선택한 인덱스의 단면을 즉시 PNG로 렌더링한다.
고정된 중앙 단면 이미지가 아니라 실제 3D 볼륨을 탐색한다.

AI 분석 화면의 M3d-CAM 이미지는 아직 시연용이므로 이번 변경 대상에서 제외했다.
