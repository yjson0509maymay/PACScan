# PACScan v1.2.4 XAI 보고서 AI 모델 정보

- 변경일: 2026-07-26 KST
- 변경 범위: XAI 보고서 상단 두 번째 정보 상자
- 기존 명칭: `AI 보조 판독 요약`
- 변경 명칭: `AI 모델`

## 변경 이유

기존 상자는 하단의 `핵심 판독 요약`과 역할이 중복됐다. 상단은 시스템 구성과
신뢰성 정보를 설명하고, 하단은 영상 판독 내용만 설명하도록 역할을 분리했다.

## 표시 정보

- 실행된 전처리: 로컬 전체 `BRAINTENSOR ref21order_v1` 또는 클라우드 경량 전처리
- 단계: DICOM 변환, BET/PD25 정합 여부, Min-Max, 56³
- N4 bias correction 미사용
- 전처리 실행 ID
- 예정 모델: 3D-CNN + 3D-ResNet
- 특징 결합: Multi-View Attention
- 설명 시각화: M3d-CAM
- 현재 상태: 모델 연결 전, 확률과 판독문은 시연용

모델이 실제로 연결되기 전에는 완료 모델 또는 임상 결과처럼 표현하지 않는다.
