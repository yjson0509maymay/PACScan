# PACScan v1.3.0 환자관리 페이지

- 변경일: 2026-07-26 KST
- 변경 범위: 상단 환자관리 메뉴 및 별도 환자관리 화면

## 구현 내용

- 상단 `뉴로렌즈(AI) 분석 결과`와 `환자관리`를 실제 이동 가능한 메뉴로 변경
- URL `?page=analysis`, `?page=patients`로 화면 상태 구분
- 가상 환자 3명 선택
- 환자 ID, 성명, 성별/나이, 생년월일, 마스킹 연락처 및 관리상태
- 검사 및 MRI 분석 이력
- 최근 임상 메모
- MRI 분석·보고서·PACScan 연동상태 요약

## 개인정보 원칙

환자관리 화면의 모든 값은 UI 시연을 위해 생성한 가상 데이터다. 화면 상단과 하단에
시연용 데이터임을 표시하며 실제 환자정보를 GitHub 코드에 저장하지 않는다.

이번 버전에서는 환자관리 UI만 구현했다. 가상 환자를 MRI 업로드 작업과 연결하거나
외부 EMR/PACS에 연동하는 기능은 포함하지 않았다.
