# PACScan v1.5.5 검사 이력 결과 연결

- 변경일: 2026-07-26 KST
- 변경 범위: 환자관리 검사 이력 → 분석 화면

## 구현 내용

- T2 MRI 검사 이력에 `분석 결과`, `XAI 보고서` 바로가기 추가
- 선택 환자 ID와 검사 식별자를 URL에 유지
- 과거 검사 바로가기는 저장된 시연 결과를 즉시 표시
- 일반 분석 화면의 DICOM 업로드 및 실제 전처리 흐름은 기존대로 유지
- MRI가 아닌 진료·검사 이력에는 결과 바로가기를 표시하지 않음

## 시연 데이터 주의

현재 검사 이력에서 열리는 AI 확률, 히트맵 및 XAI 보고서는 모델 연결 전 UI 검증을 위한 시연 결과이다. 실제 DICOM 신규 분석은 왼쪽 업로드 영역의 기존 전처리 흐름을 사용한다.
