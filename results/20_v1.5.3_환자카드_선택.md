# PACScan v1.5.3 환자 카드 선택

- 변경일: 2026-07-26 KST
- 변경 범위: 환자관리 화면 왼쪽 환자 목록

## 구현 내용

- 환자 카드 전체를 클릭 가능한 링크로 변경
- 카드 클릭 시 `page=patients`와 해당 `patient` ID를 URL에 전달
- 선택된 환자 카드는 파란 테두리와 배경으로 강조
- 마우스를 올린 카드는 테두리·배경·위치 변화로 클릭 가능 상태 표시
- 카드 클릭 후 환자 기본정보, 검사 이력, 임상 메모가 즉시 선택 환자로 변경

기존 상단 환자 선택 목록과 `MRI 분석 열기` 버튼은 키보드 접근 및 명확한 작업 흐름을
위해 그대로 유지한다.
