# PACScan v1.6.0 전체 한글·반응형 점검

- 변경일: 2026-07-26 KST
- 변경 범위: 분석 화면, 환자관리, XAI 보고서, 업로드 및 상태 패널

## 한글 줄바꿈

- 전체 요소에 `word-break: keep-all` 적용
- 공간이 부족한 경우에만 `overflow-wrap: break-word` 적용
- 업로드 제목과 안내에 남아 있던 글자 단위 강제 분리 규칙 제거
- Streamlit 가로 열의 최소 너비를 보정하여 패널 넘침 방지

## 반응형 보정

- 1100px 이하에서는 기존 설정대로 가로 열을 세로로 재배치
- 650px 이하에서 상단 메뉴의 단어 정렬과 최소 너비 보정
- 환자 정보, QC, 단계 표시의 기존 소형 화면 재배치 유지

## 한글 용어 정리

- Orientation → 영상 방향
- Intensity → 밝기 정규화
- 출력 Shape → 출력 크기
- Voxel spacing → 복셀 간격
- Multi-View Attention → 다중 시점 어텐션

MRI, DICOM, NIfTI, XAI, AI 및 모델명은 의료·기술 식별 용어이므로 원문 표기를 유지한다.
