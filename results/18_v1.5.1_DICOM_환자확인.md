# PACScan v1.5.1 DICOM 환자정보 확인

- 변경일: 2026-07-26 KST
- 변경 범위: DICOM 폴더 검사 후 분석 시작 전 안전 확인

## 구현 내용

- 환자관리에서 선택한 가상 환자의 DICOM 식별자와 업로드 `PatientID` 비교
- 일치 시 확인 메시지와 기본 `분석 시작` 버튼 표시
- 불일치 시 노란 경고와 `불일치 확인 후 분석 시작` 버튼 표시
- 불일치가 있어도 시연 및 데이터 확인을 위해 사용자가 확인 후 계속 진행 가능
- 업로드 DICOM PatientID는 앞 3자와 뒤 3자만 남기고 화면에 마스킹 표시

## 실행 로그

로컬 실제 전처리의 `run.json`에 다음 필드를 추가했다.

```json
{
  "selected_app_patient_id": "PT-DEMO-001",
  "patient_id_match": true
}
```

원본 DICOM PatientID는 실행 로그에 평문으로 저장하지 않는다. 기존 `patient_hash`만
유지한다. 이 기능은 시연용 환자 선택과 업로드 검사 간의 실수 방지를 위한 확인 단계이며,
병원 EMR의 공식 환자 매칭을 대체하지 않는다.
