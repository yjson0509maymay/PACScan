# PACScan v1.5.2 선택 환자 분석 화면 이동

- 변경일: 2026-07-26 KST
- 변경 범위: 환자관리 화면 상단 환자 선택 영역

## 구현 내용

- 환자 선택 목록 오른쪽에 `MRI 분석 열기 →` 버튼 추가
- 버튼 클릭 시 URL의 `page`를 `analysis`로 변경
- 현재 `selected_patient_id`를 URL의 `patient` 값으로 함께 전달
- 분석 화면 상단, 오른쪽 환자정보 및 향후 XAI 보고서가 같은 환자를 유지

이 버튼은 분석 화면으로 이동하는 기능만 수행한다. MRI 분석이나 전처리를 자동으로
시작하지 않으며, 의료진이 DICOM 폴더를 확인한 뒤 기존 `분석 시작` 버튼을 눌러야 한다.
