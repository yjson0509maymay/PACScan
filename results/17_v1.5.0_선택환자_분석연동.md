# PACScan v1.5.0 선택 환자 분석 연동

- 변경일: 2026-07-26 KST
- 변경 범위: 환자관리 선택 상태와 분석 화면의 시연용 환자정보

## 구현 내용

- 환자관리의 선택값을 `selected_patient_id` 세션 상태로 저장
- URL의 `patient` 파라미터에도 선택 환자 ID 유지
- 환자관리와 분석 페이지를 이동해도 선택 환자 유지
- 분석 화면 상단 환자 ID·최근 검사일 동기화
- 오른쪽 환자정보의 ID·성명·성별/나이·관리상태 동기화
- XAI 보고서의 환자 ID·검사일 동기화

## 범위 제한

연동 대상은 PACScan에 정의된 가상 환자 데이터뿐이다. DICOM PatientID를 환자관리
목록에 자동 등록하거나 실제 EMR/PACS 정보를 저장하는 기능은 포함하지 않았다.
실제 개인정보는 GitHub 코드나 URL에 사용하지 않는다.
