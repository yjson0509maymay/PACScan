# PACScan v1.4.1 원본·전처리 MRI 위치 연동

- 변경일: 2026-07-26 KST
- 변경 범위: 원본 MRI 및 전처리 결과 슬라이스 컨트롤

## 구현 내용

- 축상면·관상면·시상면 위치를 공통 0~100% 값으로 저장
- 원본 MRI와 전처리 결과가 동일한 세 위치 값을 공유
- 화면을 전환해도 슬라이더 위치 유지
- 볼륨 shape가 달라도 위치 비율을 각 볼륨의 실제 슬라이스 번호로 변환
- 배지에 `현재/전체 슬라이스`와 상대 위치 백분율을 함께 표시
- 새 DICOM 폴더 선택 시 세 연동 위치를 중앙 50%로 초기화

## 변환식

```text
slice_index = round((axis_size - 1) × position_percent / 100)
```

예를 들어 같은 50% 위치는 원본 88장 축에서 44번째 부근, 전처리 56장 축에서
28번째 부근으로 변환된다.

이 기능은 화면 비교를 위한 상대 위치 연동이다. DICOM 물리 좌표와 변환 행렬을 이용한
정밀한 세계좌표 동기화라고 표현하지 않는다.
